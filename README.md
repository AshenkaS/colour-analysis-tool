# Colour Analysis Tool

A tool for working with the electromagnetic spectrum and visible colours.

## Features
- Look up the frequency range of a colour
- Convert between frequency and wavelength
- Check whether a frequency is visible, infrared, or ultraviolet
- Identify the colour produced by a frequency and compare two frequencies
- Colour fun facts: associated stone, musical note, and emotion

- `code/`: source code and tests
